# Euclidean Algorithm

A C++ implementation of the Euclidean algorithm for finding the Greatest Common Divisor (GCD) of two numbers.

## Implementations

The program includes two approaches:

- **Iterative** – uses a `while` loop.
- **Recursive** – uses function recursion.

## Example

**Input:**
```text
1230 615
```

**Output:**
```text
Iterative result: 615
Recursive result: 615
```

## How to Run

Compile the program:

```bash
g++ algorithm.cpp -o algorithm
```

Run it:

```bash
./algorithm
```

## Language

- C++
